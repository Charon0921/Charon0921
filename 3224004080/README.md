# 论文查重程序

学号：3224004080

## 项目简介

本项目是一个基于 Python 标准库的论文查重工具。程序接收三个命令行参数（原文路径、抄袭文路径、答案路径），计算两篇文本的相似度，并将结果（0～1，保留两位小数）写入答案文件。

## 算法说明

采用**字符二元片段（bigram）+ Jaccard 相似度**算法：

1. **文本清理**：使用正则表达式去除空白和标点，只保留中文、英文和数字。
2. **二元片段切分**：将清理后的文本按连续 2 个字符切分为片段集合。例如"今天天气"切分为 {"今天", "天天", "天气"}。
3. **Jaccard 相似度计算**：比较两篇文章的片段集合，计算交集与并集的比值。

$$\text{相似度} = \frac{|A \cap B|}{|A \cup B|}$$

该算法的优势：
- 适合中文文本，不需要分词工具
- 不依赖第三方库，仅使用 Python 标准库
- 运行速度快，结果直观
- 对少量改字（如"星期天"→"周天"）仍能给出较高相似度

## 性能分析与优化

### 分析工具

使用 Python 自带的 `cProfile` 模块，对约 35 万字的模拟文本进行 10 次查重计算。

### 优化前

| 指标 | 数值 |
|------|------|
| 10 次查重总耗时 | 1.420 秒 |
| `normalize_text`（文本清理） | 1.178 秒 |
| `build_ngrams`（片段切分） | 0.231 秒 |

瓶颈在 `normalize_text` 函数：原实现使用逐字符遍历判断，效率较低。

### 优化措施

将 `normalize_text` 从逐字符循环改为使用正则表达式 `re.compile(r"[\W_]+")` 一次性替换所有非字母数字字符。算法结果不变，仅提升处理速度。

### 优化后

| 指标 | 优化前 | 优化后 | 变化 |
|------|--------|--------|------|
| 10 次查重总耗时 | 1.420 秒 | 0.320 秒 | 减少 77.5% |
| `normalize_text` | 1.178 秒 | 0.079 秒 | 减少 93.3% |
| `build_ngrams` | 0.231 秒 | 0.233 秒 | 基本不变 |
| 模拟文本相似度 | 0.62 | 0.62 | 不变 |

优化后最大耗时点为 `build_ngrams`（0.233 秒），属于生成字符片段的必要开销，当前性能已满足需求。
